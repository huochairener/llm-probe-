# LLM Probe 实现计划

> 面向 AI 代理的工作者：必需子技能：使用 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 构建一个本地 Node 桌面工具，输入 baseUrl/apiKey/协议/模型id 测试 LLM 连通性，支持单模型调试和同 apiKey 下多模型批量测试，有口令门禁和配置存储。

**架构：** pnpm monorepo，`server/`（Fastify 后端，负责 HTTP 调用/配置加密存储）+ `web/`（Vite+React 前端，负责 UI）。前后端同源（dev 时 Vite proxy 到 Fastify）。apiKey 经 scrypt 派生密钥后 AES-256-GCM 加密存储，口令门禁与加密绑定。

**技术栈：** Node 22、pnpm workspaces、Fastify、undici、React 18、Vite 5、Tailwind CSS 3、zustand、vitest。

## 任务 2：存储与加密层

**文件：** `server/src/storage.ts`

负责读写 `server/data/settings.json` 和 `server/data/configs.json`，并提供 AES-256-GCM 加解密 apiKey 的函数。密钥从口令经 scrypt 派生。

- [ ] **2.1** 实现 `storage.ts`：
  - `ensureDataDir()` — 确保 `server/data/` 存在
  - `readSettings()` / `writeSettings(s)` — settings: `{ passwordSalt: string, passwordHash: string, hasPassword: boolean }`
  - `readConfigs()` / `writeConfigs(list)` — 配置数组（apiKey 字段已是密文）
  - `deriveKey(password: string, salt: string): Buffer` — `crypto.scryptSync(password, salt, 32)`
  - `encryptApiKey(password: string, plaintext: string): string` — 生成随机 salt + iv，AES-256-GCM 加密，返回 `base64(salt.iv.ciphertext.authTag)`
  - `decryptApiKey(password: string, packed: string): string` — 反向解密
  - `hashPassword(password: string): {salt, hash}` — `scryptSync` 生成 salt + hash，都 base64
  - `verifyPassword(password, salt, hash): boolean`

```ts
import crypto from 'node:crypto'
import fs from 'node:fs'
import path from 'node:path'

const DATA_DIR = path.join(process.cwd(), 'server', 'data')
const SETTINGS_FILE = path.join(DATA_DIR, 'settings.json')
const CONFIGS_FILE = path.join(DATA_DIR, 'configs.json')

export interface Settings {
  hasPassword: boolean
  passwordSalt: string
  passwordHash: string
}

export function ensureDataDir() {
  fs.mkdirSync(DATA_DIR, { recursive: true })
}

export function readSettings(): Settings {
  if (!fs.existsSync(SETTINGS_FILE)) return { hasPassword: false, passwordSalt: '', passwordHash: '' }
  return JSON.parse(fs.readFileSync(SETTINGS_FILE, 'utf8'))
}

export function writeSettings(s: Settings) {
  ensureDataDir()
  fs.writeFileSync(SETTINGS_FILE, JSON.stringify(s, null, 2))
}

export function hashPassword(password: string) {
  const salt = crypto.randomBytes(16)
  const hash = crypto.scryptSync(password, salt, 32)
  return { salt: salt.toString('base64'), hash: hash.toString('base64') }
}

export function verifyPassword(password: string, saltB64: string, hashB64: string) {
  const salt = Buffer.from(saltB64, 'base64')
  const expected = Buffer.from(hashB64, 'base64')
  const actual = crypto.scryptSync(password, salt, 32)
  return crypto.timingSafeEqual(expected, actual)
}

// 密钥派生：用 password 当作 scrypt 输入（salt 内嵌在密文包里）
export function encryptApiKey(password: string, plaintext: string): string {
  const salt = crypto.randomBytes(16)
  const key = crypto.scryptSync(password, salt, 32)
  const iv = crypto.randomBytes(12)
  const cipher = crypto.createCipheriv('aes-256-gcm', key, iv)
  const enc = Buffer.concat([cipher.update(plaintext, 'utf8'), cipher.final()])
  const tag = cipher.getAuthTag()
  return Buffer.concat([salt, iv, enc, tag]).toString('base64')
}

export function decryptApiKey(password: string, packed: string): string {
  const buf = Buffer.from(packed, 'base64')
  const salt = buf.subarray(0, 16)
  const iv = buf.subarray(16, 28)
  const tag = buf.subarray(buf.length - 16)
  const enc = buf.subarray(28, buf.length - 16)
  const key = crypto.scryptSync(password, salt, 32)
  const decipher = crypto.createDecipheriv('aes-256-gcm', key, iv)
  decipher.setAuthTag(tag)
  const dec = Buffer.concat([decipher.update(enc), decipher.final()])
  return dec.toString('utf8')
}
```

## 任务 3：口令认证与会话

**文件：** `server/src/auth.ts`、`server/src/index.ts`（挂路由）

会话：内存中一个 Set<token>。启动时为空，必须先解锁。提供 `setupPassword`（首次）、`unlock`、`changePassword`、`logout`、`authGuard` 中间件。

- [ ] **3.1** 实现 `auth.ts`：
  - `class AuthManager`：持 `sessions: Set<string>` 和 `currentPassword: string | null`（解锁后内存缓存口令，用于解密 apiKey）
  - `isInitialized(): boolean` — 是否已设置口令
  - `setupPassword(pw): void` — hashPassword → writeSettings，缓存 currentPassword
  - `unlock(pw): string | null` — verifyPassword，通过则生成随机 token 存入 sessions 并缓存口令，返回 token；否则 null
  - `isUnlocked(token): boolean`
  - `getPassword(token): string | null` — 用于配置读写时解密 apiKey
  - `changePassword(oldPw, newPw): boolean` — 旧口令校验通过后：重算所有配置的 apiKey 密文（旧口令解密 → 新口令加密），更新 settings，更新 currentPassword
  - `logout(token): void`
  - `authGuard(req, reply)` — Fastify preHandler：检查 `req.headers['x-session']` 是否在 sessions 中，否则 401

```ts
import crypto from 'node:crypto'
import { readSettings, writeSettings, hashPassword, verifyPassword } from './storage.js'

class AuthManager {
  private sessions = new Set<string>()
  private currentPassword: string | null = null

  isInitialized() { return readSettings().hasPassword }

  setupPassword(pw: string) {
    const { salt, hash } = hashPassword(pw)
    writeSettings({ hasPassword: true, passwordSalt: salt, passwordHash: hash })
    this.currentPassword = pw
  }

  unlock(pw: string): string | null {
    const s = readSettings()
    if (!s.hasPassword) return null
    if (!verifyPassword(pw, s.passwordSalt, s.passwordHash)) return null
    this.currentPassword = pw
    const token = crypto.randomBytes(24).toString('hex')
    this.sessions.add(token)
    return token
  }

  isUnlocked(token?: string) {
    return !!token && this.sessions.has(token)
  }

  getPassword(token: string): string | null {
    if (!this.sessions.has(token)) return null
    return this.currentPassword
  }

  logout(token: string) { this.sessions.delete(token) }

  changePassword(oldPw: string, newPw: string): boolean {
    const s = readSettings()
    if (!s.hasPassword || !verifyPassword(oldPw, s.passwordSalt, s.passwordHash)) return false
    const { salt, hash } = hashPassword(newPw)
    writeSettings({ hasPassword: true, passwordSalt: salt, passwordHash: hash })
    this.currentPassword = newPw
    return true
  }
}

export const auth = new AuthManager()
```

export async function streamSSE(url: string, body: any, onEvent: (event: string, data: any) => void) {
  const res = await fetch(url, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json', 'x-session': getToken() },
    body: JSON.stringify(body)
  })
  const reader = res.body!.getReader()
  const dec = new TextDecoder()
  let buf = ''
  let curEvent = 'message'
  while (true) {
    const { done, value } = await reader.read()
    if (done) break
    buf += dec.decode(value, { stream: true })
    const lines = buf.split('\n')
    buf = lines.pop()!
    for (const line of lines) {
      if (line.startsWith('event:')) curEvent = line.slice(6).trim()
      else if (line.startsWith('data:')) onEvent(curEvent, JSON.parse(line.slice(5).trim()))
    }
  }
}
